The Evolution of Websites

Once upon a time, in the early 1990s, the internet was very simple. The first websites were created mainly to share information. These websites had only text, basic images, and links. Users could read the information, but they could not interact much with the website. This period was called Web 1.0, or the read-only web.

As technology improved, websites started becoming more interesting and interactive. Users could create accounts, post comments, upload photos, watch videos, and share information. Social media and online shopping also became popular. This new stage was called Web 2.0. Websites such as Facebook, YouTube, and Wikipedia became examples of this interactive web.

2)TCP/IP?
TCP/IP works in a similar way for data on the internet.

IP (Internet Protocol) is like the address and route system. Every device connected to a network has an IP address. IP decides where the data should go.

TCP (Transmission Control Protocol) is like the delivery manager. It breaks the data into small packets, sends them, checks whether they reached correctly, and arranges them back in the correct order.

3)LAN?

All the computers need to communicate and share files or access the internet. This small network is called a LAN (Local Area Network).

LAN = The local area where the computers are connected, like your college lab.
* IP = The address of each computer.
* TCP = Makes sure the data reaches correctly and in the right order.

4) URL, HTTP/HTTPS, IP & DNS

  1. URL – The Website Address
URL is like the complete address of a house.
Example: https://www.google.com
  2. DNS – The Name Finder
Computers communicate using IP addresses, but humans prefer names like google.com.
 3. IP – The Destination Address
After DNS finds the IP address, your computer knows where the website’s server is located.
For example:
google.com → 142.250.x.x (example IP)
 4. HTTP/HTTPS – The Communication Method
Your browser needs a way to communicate with the website’s server.
* HTTP → Transfers web data between browser and server.
* HTTPS → Secure version of HTTP; data is encrypted during transmission.

5)File Extension ?

A file extension is the set of letters written after the dot (.) in a file name.
For example:
* photo.jpg → JPG = Image
* song.mp3 → MP3 = Audio
* video.mp4 → MP4 = Video
* document.pdf → PDF = Document
* resume.docx → DOCX = Word document
* data.xlsx → XLSX = Excel file
* index.html → HTML = Web page
* style.css → CSS = Stylesheet
* program.py → PY = Python program
* app.java → JAVA = Java source code

Easy way to remember
File name + extension = File type

IDE?
IDE stands for Integrated Development Environment.

Main features of an IDE

* Code Editor → Write your program.
* Compiler/Interpreter → Converts or runs the code.
* Debugger → Finds and fixes errors.
* Auto-completion → Suggests code while typing.
* Project Management → Organizes files and folders

Simple words: IDE = A software application where you can write, run, test, and debug programs in one place.
